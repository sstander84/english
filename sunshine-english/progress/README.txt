This folder keeps Sunshine English progress safe.

The site writes progress-backup.js here automatically (Chrome or Edge, after you
connect this folder once in Settings > Keep my progress safe). When the page opens,
it loads this file, so progress comes back even after clearing the browser's
cache or history.

Using Safari? In Settings, press "Download a backup", then move the downloaded
progress-backup.js file into this folder (replace the old one).
